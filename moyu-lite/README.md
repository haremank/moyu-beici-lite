# 摸鱼背词 Lite

离线、开源、可自定义词库的"摸鱼背单词"桌面应用。基于开源项目
[qwerty-learner](https://github.com/Kaiyiwing/qwerty-learner)（GPL-3.0）+
自研 Electron 壳，参考墨鱼单词的"隐藏功能"实现（透明悬浮窗 / 老板键 / 托盘常驻）。

## 启动

双击 `start.bat`，或在命令行执行：

```
npx electron .
```

启动后会有两个窗口：

- **学习主窗口**：qwerty-learner 完整界面（打字练习、词库选择、章节、统计），纯本地运行
- **摸鱼悬浮窗**：透明置顶小卡片，可拖到屏幕任意角落，自动切词

## 悬浮窗操作

| 操作 | 效果 |
|---|---|
| 鼠标移开 | 背景变淡（默认 15%）+ **所有文字完全隐藏**，路人只看到一块几乎隐形的半透明卡片 |
| 鼠标移上去 | 背景变清晰（默认 95%），全部文字浮现，左键翻释义 |
| 左键点击 | 翻转 / 隐藏释义 |
| 右键 或 滚轮 | 切换单词 |
| **✓ 认识** 按钮（或 `Alt+2` / 长按3秒） | 标记已会：碎裂动画，自动跳下一个（后续自动跳过该词） |
| **✗ 不认识** 按钮（或 `Alt+1`） | 记一次错误（红色闪烁），自动跳下一个（单词保留在轮换里） |
| 按住拖动 | 移动悬浮窗（位置会记住） |
| **拖动右下角小手柄** | 调整悬浮窗大小（尺寸会记住） |
| 右上角 ⚙ | 打开外观设置，全部即时生效并保存：<br>· 背景平时/悬停不透明度<br>· 文字平时/悬停透明度（文字平时默认 0% = 完全隐藏）<br>· 字体发光开关<br>· 单词字体 / 字重 下拉选择<br>· **释义大小 / 释义颜色 / 释义字重**<br>· **隐藏按键说明**开关（藏起底部操作提示行）<br>· **隐藏认识/不认识按钮**（热键 Alt+2/Alt+1 不受影响）<br>· **滚轮切词开关**（防止误滚切词，可关）<br>· 单词颜色 / 辅助文字颜色 / 背景颜色 |

计数含义：`当前词/总词数 · ✓认识数 ✗错误数`。

## 跟随主窗口（默认开启）

悬浮窗默认**跟随主窗口**：你在 qwerty-learner 主界面里切换词库或章节（任务），悬浮窗会在 2 秒内自动跟着换成那一章的 20 个词（左上角词书名同步变化）。悬浮窗里翻的"已会"记录按 词库+章节 分别保存。

**主界面右下角有「● 词窗 开 / ○ 词窗 关」按钮**，一键开关单词悬浮窗，状态实时同步（Alt+Q 隐身、托盘操作后按钮显示也正确）。

想固定某本词书：托盘菜单 →「悬浮窗词书」→ 选具体书；想恢复跟随：选最上面的「跟随主窗口（词库/章节）」。

背景与文字的两档透明度也受全局热键 `Alt + ↑` / `Alt + ↓` 影响（调的是背景"悬停"档）。

## 托盘菜单（任务栏右侧 M 图标）

- 显示 / 隐藏 主窗口和悬浮窗
- **悬浮窗词书**：选择自定义词书或内置词书（CET4/6、考研、TOEFL、GRE、IELTS）
- **自动切词**：关闭 / 30 秒 / 60 秒 / 120 秒
- **悬浮窗透明度**：40% ~ 100%
- **鼠标移出悬浮窗自动隐藏**：开关（默认关）
- **导入词书…**：见下文

## 老板键与全局热键

| 热键 | 功能 |
|---|---|
| `Alt + Q` | **一键隐身**：隐藏全部窗口；再按只弹回**单词悬浮窗**（不会唤出主界面） |
| `Alt + X` | 一键退出程序 |
| `Alt + ↑` / `Alt + ↓` | 悬停时透明度 ±10%（无极调节，20%~100%） |
| `Alt + M` | 迷你模式：悬浮窗缩成一条只显示单词的小条 |
| `Alt + C` | 鼠标穿透：悬浮窗不再挡住底下程序的点击（再按恢复） |
| `Alt + 2` / `Alt + 1` | **认识 / 不认识**（作用于悬浮窗当前单词） |

隐身 / 鼠标移出隐藏期间，自动切词会**暂停**，恢复后接着学，不会漏词。

全部热键可在配置文件中修改：`%APPDATA%\moyu-lite\config.json`
（字段 `bossHide`、`bossQuit`、`opacityUp`、`opacityDown`、`miniToggle`、`clickThrough`、
`keyKnow`、`keyWrong`，改完重启生效。同一文件里还有 `autoAdvanceSeconds`、`opacity`、
`idleOpacity`、`hideOnMouseOut`、`floatBounds` 等设置。）

## 导入自己的词书

托盘菜单 → **导入词书…**，支持三种格式：

1. **txt**：每行一个词，支持以下分隔写法（`#` 开头的行是注释）：
   ```
   abandon	v. 放弃；抛弃
   ability n. 能力
   able：能够的
   ```
   （Tab / 多空格 / 冒号 / 逗号 / 竖线分隔均可，释义内的分号会拆成多条释义）
2. **csv**：第一列单词，后面各列是释义（支持引号转义逗号）
3. **json**：`[{"name":"单词","trans":["释义1","释义2"]}, ...]`（qwerty-learner 原生格式）

导入后：主窗口「词库」分类下出现"自定义"词书；悬浮窗自动切换到新书。
`moyu-lite/samples/` 里有示例文件可以试。

## 学习进度

- 悬浮窗"已会"记录：`%APPDATA%\moyu-lite\state.json`
- 主窗口（qwerty-learner）进度：本地 LocalStorage，浏览器数据目录 `%APPDATA%\moyu-lite\`

## 目录结构

```
moyu-lite/            Electron 壳（本目录）
  main.js             主进程：窗口/托盘/热键/导入/静态服务
  float.html          悬浮窗 UI 与交互
  preload.js          渲染层 IPC 桥
  lib/importer.js     词书解析（txt/csv/json → 统一格式）
  samples/            示例词书
qwerty-learner/      学习界面源码（打过补丁）
  src/resources/dictionary.ts   运行时合并 /dicts/custom/index.json
  build/                        前端构建产物（壳的 Web 根目录）
```

## 修改前端后重新构建

```
cd ../qwerty-learner && npm run build
```

## 已知限制

- 单词发音依赖有道在线 API（qwerty-learner 原设计），离线时无声；其余功能全部离线
- 固定词书模式下与主窗口各自独立选择；默认跟随模式自动同步
- Windows Smartscreen / 杀软对未签名 Electron 程序可能告警，本程序仅本地运行
